## L-System project with Raylib
A simple C++ program for visualize defined L-Systems
![Upload gif - myimgs.org](https://myimgs.org/storage/images/91482/Screenshot2026-11-23195300.png)

## Features
 - Define L-Systems in program
 - Define L-System parameters
 - Set turtle commands

## Turtle Command Sheet
- | **+** | \- rotates turtle on right
- | **-** | \- rotates turtle on left
- | **[** | \- saves turtle position and rotation
- | **]** | \- pops turtle position and rotation
- | **^** | \- pen up
- | **_** | \- pen down
- | **~** | \- randomizes next value
- | *by_user* | - moves turtle forward
